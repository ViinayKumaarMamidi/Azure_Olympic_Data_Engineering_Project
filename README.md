# Azure_Olympic_Data_Engineering_Project
This Repo holds information about Azure data engineering project

**Project Name:** Olympic Data Analytics - Azure End-To-End Data Engineering Project

**Cloud Services Used:**
 1. Azure Data Factory
 2. ADLS Gen2
 3. Databricks
 4. Azure Synapse
 5. PowerBI
    
**Programming Languages Used:**
 1. Python
 2. Pyspark
 3. SQL

**Data Flow:** Using Azure Data Factory to load the data into ADLS Gen2 storage and leveraging Pyspark in Databricks to transform the raw data and using Synapse and performing analytical query executions and building reports on the top of the analytical queries
